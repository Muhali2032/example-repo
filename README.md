# Holiday Cost Calculator

## Project Description

This Python application calculates the total cost of a holiday based on the destination, number of hotel nights, and car rental days.

The application uses separate functions to calculate hotel accommodation, flight costs, and car rental costs. It then combines these amounts to display the total holiday cost.

## How to Run

1. Open the project folder in Terminal.
2. Run the command: `python3 holiday.py`
3. Enter the requested destination, number of nights, and car rental days.

## Supported Destinations

- Port Elizabeth
- George
- East London
- Cape Town
